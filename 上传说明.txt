===========================================
            GitHub 上传说明
===========================================

使用手机上传步骤：

1. 打开 GitHub App 或在浏览器中打开您的仓库
2. 进入仓库后，点击右上角的 + 号
3. 选择 "Upload files"
4. 选择这个文件夹里的所有文件：
   - main.py
   - buildozer.spec
   - .github/workflows/build.yml
5. 点击 "Commit changes"
6. 上传完成后，去 Actions 标签页
7. 运行 "Build Android APK" 工作流
8. 等待构建完成后下载 APK
